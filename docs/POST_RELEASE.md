## Zgłaszanie problemów

Do zgłoszenia dołącz zrzut ekranu, nazwę ekranu lub dialogu, widoczny tekst,
wersję spolszczenia, hash pobranego ZIP-a oraz kroki pozwalające odtworzyć
problem. Nie dołączaj prywatnych ścieżek ani danych osobowych.

W razie krytycznego problemu oznacz lub usuń publiczne wydanie GitHub Release,
zastąp je komunikatem o wycofaniu oraz poinformuj użytkowników, aby nie
instalowali paczki. Po przygotowaniu poprawki opublikuj nowy ZIP i nową sumę
SHA-256; nie podmieniaj niejawnie już pobranego archiwum.
